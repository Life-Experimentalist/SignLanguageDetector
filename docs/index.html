End-to-End Pipeline

This is the complete project flow from collecting images to final inference in the browser and API.

Step 1

Collect Raw Images

Capture sign-class images into class folders under data using the collector script. 

uv run --python .venv\Scripts\python.exe python training/collect_imgs.py

Step 2

Create Dataset Features

Convert images into normalized hand-landmark features. Frames with no detected hand or excessive blur are rejected. 

uv run --python .venv\Scripts\python.exe python training/create_dataset.py

Step 3

Train Classifier

Train the RandomForest model and export model, text report, and JSON metrics. 

uv run --python .venv\Scripts\python.exe python training/train_classifier.py

Step 4

Convert and Inspect Reports

Convert existing reports and surface highlights such as top classes, weak classes, and aggregate quality metrics. 

uv run --python .venv\Scripts\python.exe python training/convert_model_reports.py

Step 5

Serve App + API

Launch Flask to use the live webcam interface and direct image prediction API at /api/predict. 

uv run --python .venv\Scripts\python.exe python app.py

Step 6

Final Inference Modes

Run inference from browser camera stream, model switching UI, or backend API integration for external clients.

  • Web: live camera feed with landmarks
  • API: single image predictions without webpage
  • Reports: post-training performance visibility
