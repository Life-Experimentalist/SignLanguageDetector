# Branding Prompts

Use these prompts with your preferred image generator. Export in high quality and place files in:

- `docs/static/branding/logo-mark.png`
- `docs/static/branding/hero-banner.jpg`
- `docs/static/branding/social-banner.jpg`

## Logo Prompt

Design a clean, modern logo mark for "Sign Language Detector". Theme: accessibility, hand gestures, computer vision. Visual style: geometric hand silhouette combined with subtle pixel or landmark node accents. Color palette: deep teal, warm orange, neutral off-white. No gradients inside the icon. Flat vector look, strong silhouette, high legibility at small sizes, transparent background, square composition, no text.

## Hero Banner Prompt

Create a cinematic hero banner for a developer-focused open-source project called "Sign Language Detector". Show a person making a hand sign with abstract hand-landmark overlays and thin connection lines, plus subtle code-like UI cards in the background. Keep it bright and optimistic. Color direction: teal, amber, soft sky blue, off-white. Composition should leave safe space on the left for headline text. Horizontal 16:9, high detail, realistic but clean, no watermarks, no random text.

## Social Banner Prompt

Create a professional social sharing banner for "Sign Language Detector". Include a bold visual of hands in frame, lightweight landmark dots/lines, and a modern tech atmosphere. Add room for title text area, but do not render actual text. Contrast should work on Twitter and Open Graph cards. Color system: teal and orange with neutral background, sharp and crisp. Aspect ratio 1200x630, web-optimized, no watermark.
